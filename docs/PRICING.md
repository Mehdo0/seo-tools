## ❓ FAQ Paiement

### Quels moyens de paiement acceptez-vous ?

- **Extension Premium** : carte bancaire via Stripe Checkout (Visa, Mastercard, American Express)
- **Scraping** : virement bancaire (RIB français) ou paiement par carte via Stripe (lien de paiement envoyé par email)

### Puis-je changer de formule en cours de route ?

Pour l'extension **Premium**, passez du mensuel à l'annuel à tout moment — la différence est calculée au prorata. Pour le **Scraping**, un package Basic peut être étendu vers Pro avant livraison.

### La TVA est-elle incluse ?

Les prix indiqués sont **Hors Taxes (HT)**. La TVA française (20 %) s'applique pour les clients particuliers et les entreprises françaises non assujetties. Les entreprises européennes avec numéro de TVA intracommunautaire valide sont exonérées (autoliquidation).

### Puis-je obtenir une facture ?

Oui, une facture au format PDF est émise automatiquement pour chaque paiement. Pour le scraping, la facture est envoyée avec le livrable final.

### Quelle est la politique de remboursement ?

- **Extension Premium** : satisfait ou remboursé sous 14 jours. Annulation possible à tout moment depuis votre compte Stripe.
- **Scraping** : remboursement de l'acompte (50 %) si le projet n'a pas démarré. Après livraison, les révisions incluses permettent d'ajuster le livrable à vos besoins.

### Proposez-vous des réductions pour les agences ?

Oui ! Contactez-nous à `pro@votre-domaine.com` pour les offres multi-utilisateurs (extension) et les contrats cadre (scraping).
