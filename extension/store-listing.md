## STORE LISTING (English)

### Short Description (max 132 chars)
Analyze any page's SEO in one click. Meta tags, headings, keywords, images, links. Free Chrome extension. Built by developers, for developers.

### Detailed Description
SEO Inspector is a professional on-page SEO analysis tool that audits any webpage in one click. Built with Manifest V3 for speed and privacy.

**What it analyzes:**
- Meta tags (title, description, OG, Twitter cards)
- Heading structure (H1-H6 hierarchy)
- Keyword density and top phrases
- Images (alt text, missing attributes)
- Internal and external links
- Schema.org structured data
- Mobile viewport optimization
- Readability score (Flesch-Kincaid)
- Overall SEO score (0-100 with letter grade)

**No account required. No data leaves your browser.** The entire analysis runs locally on your machine using Chrome's built-in DOM parser.
